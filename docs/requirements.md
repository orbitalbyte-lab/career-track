# CareerTrack — Requirements

## 1. Project Overview

CareerTrack is a job and internship application tracking system designed to help students and job seekers organize, track, and analyze their career applications.

## 2. Problem Statement

Job seekers often apply to many internships and jobs across different companies. Without a centralized system, it can be difficult to remember application dates, deadlines, interview schedules, follow-ups, and application outcomes.

CareerTrack provides a centralized platform for managing this information.

## 3. Target Users

- University students
- Internship seekers
- Recent graduates
- Job seekers
- Early-career professionals

## 4. Core Features

### Application Management

Users can:

- Create applications
- View applications
- Update applications
- Delete applications
- Search applications
- Filter applications

### Company Management

Users can:

- Add companies
- View companies
- Update companies
- Delete companies

### Interview Management

Users can:

- Schedule interviews
- View upcoming interviews
- Update interview information
- Record interview notes

### Follow-up Management

Users can:

- Create follow-up reminders
- View upcoming follow-ups
- Mark follow-ups as completed

### Dashboard

The system should provide statistics including:

- Total applications
- Applications by status
- Total interviews
- Total offers
- Total rejections
- Application response rate
- Interview rate

## 5. Application Statuses

- Wishlist
- Applied
- Under Review
- Interview
- Offer
- Rejected
- Withdrawn

Potential future improvements include:
